"신뢰도 ★★★"은 3개 휴리스틱 통과를 의미할 뿐 법적 정확성을 보증하지 않습니다. 관세 시나리오 계산기는 단순 산술 모델이며 실제 거래에는 부가세·원산지 규정·계약 조건 등이 추가로 반영되어야 합니다. 실제 법률·통상 판단에는 원문 및 전문가 자문이 필요합니다.

AI 답변 설정

API 키는 이 브라우저(localStorage)에만 저장되며 별도 서버로 전송되지 않습니다. 질문 시 키는 Anthropic API로만 직접 전송됩니다. 공용 기기에서는 사용 후 '키 삭제'를 눌러주세요.
